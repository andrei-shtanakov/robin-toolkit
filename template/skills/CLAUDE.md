# skills/ — reusable team skills
Saved instructions your agents apply (design, copy, decisions, prototyping…). One folder per skill: a clear name, a description of *when* to use it, and the instruction itself. Add via PR. Improvements to the toolkit skills go to github.com/BayramAnnakov/team-os-toolkit.
